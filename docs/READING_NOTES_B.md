## Paper 1：Detecting and Predicting Forecast Breakdowns

### 研究問題

一個模型在過去資料上表現不錯，是否代表它在未來也能維持相近表現？如果未來表現惡化，能否判斷這不是一般抽樣波動，並利用已知資訊預測後續惡化？

作者關注的不是「模型是不是真實世界的正確方程式」，而是它的樣本外表現是否符合根據樣本內表現形成的期待。這容許模型本來就有設定錯誤：模型不完美，仍可具有穩定、可預期的損失。

可以拆成三個問題：

1. **偵測**：樣本外損失是否顯著高於樣本內損失？
2. **理解機制**：參數改變、擾動變異改變、有限樣本過度擬合等，如何形成這種差距？
3. **預測**：能否以過去可取得的資訊，解釋或預測未來的額外損失？

定位：公開版 §§2–6，印刷頁 6–20。

### 資料

本篇結合理論推導、Monte Carlo 模擬及美國通膨實證；沒有使用電力或氣象資料。

**模擬資料**用於檢查沒有失效時是否誤報、存在不穩定時能否偵測，以及與結構變動檢定的差異。模擬中的資料生成機制已知，因此可區分真實狀態與檢定結果。

**實證：Phillips curve 通膨預測。** 模型以失業率及通膨變化的落後項預測未來通膨變化，討論失業資訊的預測作用能否維持。

| 項目 | 公開版 §9 的設定 |
|---|---|
| 即時資料 | Philadelphia Fed 即時資料庫；消費者物價另使用 Swanson、van Dijk、Callan 資料 |
| 即時資料涵蓋 | 1961:1–2001:12；第一個 vintage 為 1978:2 |
| 即時估計範圍 | 因資料限制使用 1978:2–2001:12 的 quarterly vintages；不是把所有歷史數字當作當時已知 |
| 即時資料預測期距 | 3、12 個月；不同落後期規格及 BIC 選擇 |
| 即時估計視窗 | rolling scheme，m = 60；這不能解讀為丹麥資料應用 60 小時 |
| 修訂後資料 | 2004:8 vintage；CPI 與失業率最大共同樣本 1948:1–2004:6 |
| 後續解釋變數 | 通膨波動程度、估計的 Fed 政策反應係數 |

**資料版本的教訓：** 使用今天修訂後的數字回推歷史預測，與真正站在當時預測不是同一個實驗。LoadPulse 應記錄用電資料更新／修訂狀態、缺值修補方式及每個預測時點可取得的資訊。

### 方法

**1. 先指定 forecasting scheme。**

| 方式 | 如何使用歷史資料 | 意義 |
|---|---|---|
| Fixed | 固定初始估計樣本 | 模型能否延伸到後續期間 |
| Rolling | 固定筆數的移動估計視窗 | 模擬持續適應近期資料的模型 |
| Recursive | 逐漸擴大的估計樣本 | 每次納入所有已取得歷史資料 |

這些是模型估計方式；不要與 LoadPulse 用來定位失效的「局部評估視窗」混為一談。

**2. 分開 forecast error 與 loss。** 用便於理解的符號：

$$
e_{t+h}=y_{t+h}-\hat y_{t+h|t},\qquad L_{t+h}=L(e_{t+h}).
$$

例如平方損失為 $e^2$，絕對損失為 $|e|$。前者更重罰大偏差。帶正負號的 error 說明高估／低估；loss 說明表現代價，不應互換。

**3. 建立 surprise loss。** 公開版式 (1)：

$$
SL_{t+h}(\hat\beta_t)=L_{t+h}(\hat\beta_t)-\bar L_t(\hat\beta_t).
$$

$\bar L_t$ 是與該次估計樣本相對應的平均樣本內損失；同一組當時估計的參數同時用於比較。正值代表這次樣本外損失高於模型在估計樣本中的平均損失。

**教學例子，非論文數據：** 歷史平均平方損失為 100，新觀測平方損失為 225，則 surprise loss = 125。但「125 > 0」本身不等於統計顯著。

**4. 對平均 surprise loss 做單尾檢定。** 公開版式 (2)–(4) 先聚合樣本外 surprise losses，檢定其平均期待值為零的虛無假設，針對正方向拒絕：

$$
T=\frac{\sqrt n\,\overline{SL}}{\hat\sigma}.
$$

$\hat\sigma$ 不是隨意計算的一般樣本標準差。作者 §3.5 推導適合 forecasting scheme 的漸近變異數，處理估計不確定性與時間相依結構。在其條件下，統計量可使用標準常態上尾臨界值。

這裡的「變差」是損失變大；若只是表現變好，通常不算 breakdown。作者亦討論特殊目的下可採雙尾檢定，但不能因此把所有表現變動一律叫作失效。

**5. 處理 overfitting。** 訓練參數是為了降低樣本內損失，因此有限樣本下即使機制穩定，樣本外損失也可能較高。§5 提出修正；不能用未校正的 train–test gap 直接證明結構改變。

**6. 用額外資訊預測 surprise loss。**§6 及實證式 (24) 的思路是：

$$
SL_{t+h}=\delta_0+z_t'\delta_1+\varepsilon_{t+h}.
$$

$z_t$ 可包含落後 surprise loss 或有意義的經濟資訊。這是對「模型表現」再建立模型。若宣稱預測未來，$z_t$ 必須在預測當下可用；事後才知道的變數只能支援回顧分析。

### 核心發現

1. **預測表現穩定與參數穩定並不相同。** 參數改變可能造成失效，但擾動變異增加也能使平方損失惡化；拒絕檢定不能單獨辨認是哪個原因。
2. **過度擬合是需要處理的替代解釋。** 樣本內／外差距不是結構性失效的充分證據。
3. **偵測能力取決於不穩定的型態。** 作者理論與模擬指出，永久變動時結構變動檢定可能較有力；反覆出現且模型未捕捉的不穩定，forecast breakdown test 在部分設定下可能更有力。不是本方法全面優於其他檢定。
4. **Phillips curve 有部分失效證據，且取決於資料版本和期距。** 公開版 Table 3：即時資料在一年期較有力，短期較弱；修訂資料在一個月期有部分證據，較長期距不明顯。不能概括為「Phillips curve 全面失效」。
5. **通膨波動與政策反應變數能解釋部分 surprise loss。** 這支持對失效進行後續條件分析，但不是直接的因果識別，更不是氣象與用電的實證結果。

來源：[公開全文 §§3–9](https://www.ecb.europa.eu/pub/pdf/scpwps/ecbwp638.pdf)。

### 作者如何定義 error / failure / anomaly

| 名詞 | 本篇可支持的理解 | 不可擅自等同 |
|---|---|---|
| Forecast error | 實際值相對預測值的差異，可由 loss function 評價 | 有 error 就有 failure |
| Surprise loss | 樣本外損失減去對應樣本內平均損失 | 任一正值就是顯著失效 |
| Forecast breakdown | 在指定損失與推論框架下，樣本外表現顯著惡於樣本內表現 | 停電、量測異常、結構方程式必然改變 |
| Anomaly | 本篇未提供 LoadPulse 所需的一般逐點異常標籤定義 | 自動套成 residual 超過 3σ |

**準確的口頭說法：**「作者把失效操作化為相對於過去擬合表現、樣本外損失顯著上升的現象；它是預測表現的診斷，不等於已找到原因。」

### 與 LoadPulse 哪一步有關

| 步驟 | 連結 | 限制 |
|---|---|---|
| Step 1：時間基準模型 | 固定估計方案、期距、loss 與資訊集合 | 原文沒有指定用電時間模型 |
| Step 2：局部失效偵測 | 最直接：以額外損失和統計證據定義惡化 | 原檢定不會自動提供每小時事件邊界 |
| Step 3：跨模型驗證 | 每個模型可分別形成失效證據 | 多模型共同顯著仍須處理相依性 |
| Step 4：特徵描述 | 保留 error 方向與 loss 大小 | 持續時間、恢復速度須自行定義 |
| Step 5：氣象關聯 | 模仿對 surprise loss 做後續條件分析 | 換成天氣是新研究，不能借用原文因果結論 |

### 可以直接借用的方法

「直接」指可採用統計設計，仍須確認假設及估計量適用。

- 用明確 loss 衡量表現，不以主觀挑圖定義失效。
- 把相對歷史期待的額外損失作為診斷量。
- 固定估計方案、預測期距與資訊可用時間。
- 對時間相依與參數估計不確定性採合適推論。
- 把失效偵測與後續解釋分成兩個階段。
- 先以已知穩定／已知改變的模擬資料檢查誤報率和偵測能力。

### 不能直接借用的地方

- **不能把 m = 60 等數字照搬為用電視窗。** 月資料與小時資料的週期和有效樣本數不同。
- **不能把一般 rolling mean + 1.645 當作原方法。** 局部掃描、重疊視窗與不同估計方案改變推論問題。
- **不能只檢定挑中的幾段。** 先看圖選出極端時段再檢定，會產生選擇偏誤。
- **不能把原文過擬合修正無條件移植到任意機器學習模型。** 需檢查其推導條件。
- **不能由拒絕檢定宣稱「時間資訊在原理上無法解釋用電」。** 最多支持所測模型與資訊設定的不足。
- **不能直接說天氣造成失效。** 需排除資料問題、假日編碼、產業活動、長期負載變化等替代解釋。

## Paper 2：The Model Confidence Set

### 研究問題

有很多候選模型時，樣本平均誤差最小的模型是否真的最好？若資料不足以辨別，是否應保留一組仍合理的候選，而不是硬選一個冠軍？

作者提出 MCS，以指定評價準則界定「最佳」，再以統計程序估計包含最佳模型的集合。模型不必有任何一個等於真實資料生成機制；最佳是相對於事先給定候選集與 loss。

### 資料

本篇有理論、模擬與**兩個**實證應用，不能只寫成 GARCH 波動預測研究。相同作者另有 2003 年波動模型文章，不是教授指定的 2011 年這篇。

| 應用 | 公開版全文的資料與設定 |
|---|---|
| 美國通膨預測 | 重訪 Stock & Watson (1999)；CPI-U all items（PUNEW）與個人消費支出平減指數（GMDC） |
| 完整資料範圍 | 1959:M1–1997:M9 |
| 預測評估子期間 | 1970:M1–1983:M12、1984:M1–1996:M9；完整資料終點不等於評估終點 |
| 候選模型 | Table 4 有 19 個：Phillips curve 類、其他總體指標、自迴歸及兩種 no-change；Table 5 另分析因子／組合預測 |
| 估計方式 | 主文使用固定筆數 rolling window，以配合損失差的穩定性要求 |
| 通膨 bootstrap | 主設定 block length = 12；附錄另比較 6、9，不代表所有時間序列都用 12 |
| Taylor rule | 美國 1979:Q1–2006:Q4，25 個規格，包括 24 個政策反應回歸及聯邦基金利率 AR(1) |
| 政策規則變數 | 聯邦基金利率、GDP 平減指數通膨、產出缺口；另以失業率缺口或實質單位勞動成本替代活動變數 |
| 政策規則評價 | 樣本內 likelihood 及考慮有效自由度的資訊準則；不是單純以樣本外 RMSE 排名 |

定位：公開版 §6.1 印刷頁 25–29、§6.2 頁 29–34。

### 方法

**1. 指定候選集合與損失。**

$$
M_0=\{1,\ldots,K\},\qquad L_{i,t}=L(y_t,\hat y_{i,t}).
$$

同一個 t 應代表相同預測目標與期距。不能讓模型 A 評估一組容易的日期，模型 B 評估另一組困難日期。

**2. 用損失差比較模型。**

$$
d_{ij,t}=L_{i,t}-L_{j,t},\qquad \bar d_{ij}=n^{-1}\sum_t d_{ij,t}.
$$

正值代表 i 在該評價上較差。相對比較與第一篇「同一模型相對過去表現」不同。

**3. 定義最佳模型集合。** 在固定預測評價問題中可寫成：

$$
M^*=\{i\in M_0:E[L_{i,t}]=\min_{j\in M_0}E[L_{j,t}]\}.
$$

可以有多個並列最佳。MCS 是對這個未知集合的統計估計，不是宣稱找到唯一真實模型。

**4. 檢定目前集合內的 equal predictive ability。**

$$
H_{0,M}:E[d_{ij,t}]=0\quad\text{for all }i,j\in M.
$$

作者提出檢定與淘汰規則相互配合的程序。以標準化成對損失差的 range statistic 為例：

$$
t_{ij}=\frac{\bar d_{ij}}{\widehat{se}(\bar d_{ij})},\qquad T_R=\max_{i,j\in M}|t_{ij}|.
$$

也可利用模型相對集合平均的損失構造統計量。**不能檢定用一套、淘汰任意選最大 RMSE**；淘汰規則須與檢定一致。

**5. 反覆檢定與淘汰。**

1. 由完整候選集合開始。
2. 檢定目前集合是否能維持等預測能力假設。
3. 若拒絕，依相容規則移除較差模型。
4. 對縮小集合重做檢定。
5. 無法拒絕時停止，得到 MCS。

**6. 透過 bootstrap 推論。** 時間序列重抽樣須保留時間相依；所有模型也須採相同抽樣時間索引，以保留模型間相關。獨立打散每個模型的誤差欄位會破壞比較結構。

公開版 Assumption 2 特別對 **loss differentials** 要求嚴格平穩、適當動差與弱相依。不是簡單要求所有原始用電值或每個模型的 loss 都必須不變；若共同變動在相減後抵消，loss 可以不平穩而 loss difference 仍穩定。

### 核心發現

1. **應承認模型選擇的不確定性。** 資料資訊充足，MCS 可以很小；資訊不足，集合可能包含很多模型。
2. **有限樣本的 MCS 可能保留不好模型。** 留下表示尚無足夠證據淘汰，不是通過絕對品質認證。
3. **通膨子期間的可辨識性不同。** 公開版 Table 4 的 75% MCS：1970–1983 年，PUNEW 留 7 個、GMDC 留 9 個；1984–1996 年兩者均只排除 19 個中的 1 個，保留 18 個。這是特定信賴水準與模型集的結果，不能改說成 95%。
4. **月對月 no-change 表現較弱。** 較晚期間年對年 no-change 可留在集合中；不能把所有「不變預測」都當成一種模型。
5. **Taylor rule 無法選出唯一規格。** 多個政策規則及 AR(1) 可留在集合中，顯示資料辨別力有限；不能由某規格留下就推導政策因果有效性。

來源：[公開全文 §§2–3、6–7](https://repec.econ.au.dk/repec/creates/rp/10/rp10_76.pdf)。

### 作者如何定義 error / failure / anomaly

| 名詞 | 本篇的角色 |
|---|---|
| Error／loss | 模型的預測誤差由指定損失評價；其他應用也可採不同準則 |
| Loss differential | 同一觀測下模型 i 與 j 的損失差 |
| Inferior model | 在指定候選集、準則及程序下，可被判定相對較差而排除的模型 |
| Failure | 沒有定義 LoadPulse 的局部時間失效事件；模型被排除不等於某時段失效 |
| Anomaly | 沒有提供逐點異常偵測標籤 |

95% MCS 的信賴解釋是程序在其適用條件下的涵蓋性質，不能說「每個留下模型都有 95% 機率正確」。也不能說「未拒絕等能力」等於「證明能力相同」。

### 與 LoadPulse 哪一步有關

主要連結 **Step 1 的模型評估與 Step 3 的跨模型驗證**。它可以避免只選整體 RMSE 最低者，也可描述某段較長評估期間中哪些時間模型尚未被淘汰。

但 Step 2 仍需獨立的失效定義。Step 4 的持續時間、高低估、恢復速度，也不是 MCS 的輸出。

### 可以直接借用的方法

- 用對齊的 loss matrix 作多模型比較：列為評估時間、欄為模型。
- 用集合保留不確定性，代替硬選單一冠軍。
- 採符合時間相依的 bootstrap，保留模型間配對結構。
- 同時报告樣本大小、模型列表、loss、信賴水準、block length、重抽樣次數、MCS 結果。
- 對合理替代 loss、樣本切分與 bootstrap 設定進行事前規劃的敏感度分析。

### 不能直接借用的地方

- **MCS 不能直接偵測共同失效。** 它比較相對損失，沒有評價共同增加的絕對損失。
- **不能把留在 MCS 稱為「通過穩健失效驗證」。** 未被淘汰是相對結論。
- **不能對每個小時單獨執行可靠的 MCS。** 單點沒有足夠時間樣本估計比較不確定性；極短視窗也可能低檢定力。
- **不能無條件在結構變動前後混合抽樣。** 若損失差本身改變，原推論條件可能不成立。
- **不能照搬 Taylor rule 的樣本內 likelihood 流程到用電預測。** 研究目標不同，應先採對齊的樣本外 loss。
- **不能先用整段測試資料挑好模型，再把同段當獨立證據。** 模型篩選與失效驗證須避免資料重用偏誤。

## 兩篇的對照與必要反例

| 比較面向 | B1 Forecast breakdown | B2 MCS |
|---|---|---|
| 比較對象 | 同一模型的样本內／外表現 | 同時期不同模型 |
| 核心量 | Surprise loss | Loss differential |
| 主要問題 | 是否比期待更差 | 哪些候選可被淘汰 |
| 主要輸出 | 惡化的統計證據；條件損失分析 | 尚不能排除的候選集合 |
| 不能回答 | 惡化的唯一原因 | 所有模型是否一起變差 |

**共同失效反例，以下數字為自製教學例子：**

| 時段 | A 損失 | B 損失 | C 損失 | A−B |
|---|---:|---:|---:|---:|
| 一般時段 | 10 | 12 | 11 | −2 |
| 共同惡化時段 | 110 | 112 | 111 | −2 |

每個模型都多了 100，但相對差距完全沒變。

若 $L_{i,t}=a_i+c_t$，則 $d_{ij,t}=a_i-a_j$，共同衝擊 $c_t$ 在 MCS 比較中抵消。這說明「模型彼此差不多」與「模型都表現很好」是不同命題。

## LoadPulse 可採用的操作定義草案

**以下為本研究建議，不是兩篇論文的既有定義，也尚未經 DK1／DK2 實驗驗證。**

### 1. 先修正研究主張

附件允許模型知道過去用電，因此嚴格而言不是純 calendar-only，而是「日曆與負載歷史、未顯式使用氣象」的資訊集合。過去用電可能已間接包含天氣影響。

建議把核心問題寫成：**在指定預測期距、訓練方案及不含顯式气象變數的模型集合下，是否存在超出歷史預期的局部樣本外損失，且跨模型重現？**

這比「時間無法解釋用電」精確。預測誤差也不等於結構性／因果解釋能力。

### 2. 固定資料與實驗規則

- DK1、DK2 分別分析，再比較事件是否同步；原始負載量不同，不直接比較平方誤差大小。
- 先定預測期距：例如一小時前預測或日前預測，不能混為同一任務。
- 按時間切出訓練、校準／開發、最終評估期間；所有縮放、門檻與超參數只從允許期間估計。
- 排查缺值、重複時間、夏令時間、單位轉換、資料修訂、假日編碼。
- 保留不同模型家族，避免十個近乎相同模型被當成十份獨立支持。

### 3. 建立公平的額外損失基準

為減少複雜模型訓練誤差偏低的問題，可從歷史 rolling-origin 樣本外預測建立校準基準，而不直接使用訓練誤差。

令 $\mu_i(c_t)$ 為模型 i 在相似日曆條件下的歷史期待損失，則：

$$
u_{i,t}=L_{i,t}-\hat\mu_i(c_t).
$$

$c_t$ 可包含小時、星期、季節，但需避免分組太細造成樣本不足。**這是受 surprise loss 啟發的修改版，不是 B1 原檢定；必須重新校準不確定性與誤報率。**

### 4. 定義局部失效

對預先指定視窗 $W$，計算：

$$
A_i(W)=|W|^{-1}\sum_{t\in W}u_{i,t}.
$$

建議同時要求：

1. 超額損失為正且超過事前定義的實務門檻 $\delta_i$。
2. 在適合時間相依、包含基準估計不確定性的推論下，具有惡化證據。
3. 掃描多個視窗、模型及視窗長度時，處理整體多重檢定。
4. 已通過資料品質檢查。

24 小時、72 小時、一週只能作候選尺度，不能未驗證就宣稱最佳。統計顯著與實務重要須同時報告；「不顯著」也不等於證明沒有失效。

### 5. 定義 Robust Temporal Failure

在事前固定的多樣模型集合中，要求同一事件在足夠比例模型上符合失效規則。比例與時間重疊容許值應在看最終結果前訂定，並用模擬檢查共同誤報率。

**多模型不是獨立投票。**共用資料、特徵或訓練期間會使錯誤相關；可用聯合區塊重抽樣保留跨模型與時間相依。MCS 用來補充「是否有模型明顯較差」，不能取代共同失效統計量。

局部視窗的重疊命中也不是多個獨立事件。應先訂相鄰命中合併規則，再記錄起迄、方向、超額損失、持續長度及恢復情形。視窗命中範圍不等於真正的物理事件邊界。

### 6. 最後才分析氣象

先凍結失效標籤，再開啟天氣資料；同季節、星期、時段比較 failure／non-failure，避免冬天既較冷又更難預測造成表面關聯。

可分兩個問題：

- **關聯問題：** 天氣條件與超額損失／失效事件是否有穩定關聯？
- **增量預測問題：** 加入天氣後，能否在獨立評估期間減少原先失效時段的損失？

兩者都不自動證明因果。若用觀測到的未來天氣改善日前預測，只能稱為事後／理想資訊分析；真正可部署預測需使用當時可取得的天氣預報。

## 教授可能追問的問題與答法

**Q：只要誤差大就是 failure 嗎？**

A：不是。需相對公平的歷史期待，並有統計與實務上的惡化。模型長期都很差可能是一般模型不足，不是局部 breakdown。

**Q：為什麼不用 residual > 3σ？**

A：這可作候選異常規則，但未處理時段差異、自相關與大量掃描，也不同於 forecast breakdown 的表現比較。我們會校準它的誤報率，而非把它當自然真理。

**Q：MCS 留下的模型是否都一樣好？**

A：只能說目前資料不足以依該程序淘汰它們。有限樣本可能留下差模型。

**Q：三個模型一起錯，是否證明天氣造成？**

A：只能增加現象不侷限單一模型的可信度。共同資料錯誤、共用特徵不足等仍可造成共同錯誤。

**Q：為什麼不一開始就加天氣追求更準？**

A：研究先辨認未顯式使用天氣的模型在哪裡惡化，再檢查天氣是否提供增量資訊。若同時看天氣調門檻，就有循環論證風險。

**Q：B1 已經有統計方法，為何還要設計自己的規則？**

A：原文提供樣本內／外表現比較；我們要找小時級局部事件，還多了視窗掃描、事件合併、跨模型一致性與季節性校準，這些不能假裝原文已解決。

**Q：這兩篇能否支持 H1？**

A：提供工具與限制，不能替丹麥用電資料預先證明 H1。若校準後找不到可重現失效，也必須接受結果。

## 分享時可採用的順序

1. 先解釋 error、loss、breakdown 的差異。
2. 用 surprise loss 的小例子介紹 B1，再說明統計檢定與過擬合修正的重要性。
3. 說明 B1 的通膨結果會隨資料版本和期距改變。
4. 用「保留候選而非硬選冠軍」介紹 B2，列出兩個實證應用。
5. 展示共同增加 100 的反例，解釋 MCS 不能偵測共同失效。
6. 提出 LoadPulse 的兩層設計：先偵測單模型局部惡化，再評估跨模型一致性；最後分析氣象。
7. 請團隊決定預測期距、局部視窗、損失函數、模型家族及實務門檻，而非先決定要找出幾個事件。
